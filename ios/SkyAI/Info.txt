SkyAI iOS SwiftUI App - Complete Implementation
================================================

PROJECT STRUCTURE:
/Models/Flight.swift - All data models and Codable structures
/Services/APIClient.swift - Async/await URLSession API client
/ViewModels/SearchViewModel.swift - Search input and intent parsing logic
/ViewModels/ResultsViewModel.swift - Flight results and sorting logic
/Views/SearchView.swift - Natural language search + structured form UI
/Views/ResultsView.swift - Results list with sorting and Pareto bar
/Views/FlightCardView.swift - Individual flight offer card component
/Views/FlightDetailView.swift - Full flight details page
/Views/ContentView.swift - Tab bar root view with placeholder tabs
/SkyAIApp.swift - App entry point

KEY FEATURES:
✓ Complete data models with snake_case CodingKeys for backend JSON
✓ Actor-based APIClient with proper error handling
✓ Async/await throughout - no completion handlers
✓ SearchRequest defaults: today+30 days, 1 adult, economy roundtrip
✓ Intent parsing with interpretation display and animations
✓ Structured form with airport pickers, date selection, passenger counts
✓ Results view with three sort options (price, duration, best deal)
✓ Skeleton loading animation while fetching
✓ Error states with retry button
✓ Empty state handling
✓ Pareto bar showing cheapest, fastest, best deal shortcuts
✓ Price intelligence display with percentile rank bar
✓ Price trend indicators with icons
✓ Detailed flight information with all segments
✓ Fare conditions, baggage, and booking details
✓ Navigation using NavigationStack + .navigationDestination
✓ Design: Deep blue primary (#1A3C6B), orange accent (#FF6B35)
✓ Production-quality shadows, corner radii, and typography
✓ SF Symbols throughout
✓ iOS 17+, Swift 5.9+ compatible

DEPENDENCIES:
- Foundation (URLSession, JSON encoding/decoding)
- SwiftUI (all UI)
- No external packages required

BACKEND INTEGRATION:
- Base URL: http://192.168.86.144:8000 (Mac LAN IP — update when network changes)
- Simulator alt: http://localhost:8000
- POST /search/intent - Parse natural language query
- POST /search/flights - Search with SearchRequest
- JSON uses snake_case (auto-converted by JSONEncoder/Decoder)
- ISO8601 date format
