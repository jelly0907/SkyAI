NAVIGATION ROUTES
==================
1. "search" → SearchScreen
   - Start route
   - Natural language query input
   - Intent parsing and form population

2. "results/{requestJson}" → ResultsScreen
   - JSON string parameter (URL encoded)
   - Flight list with sorting
   - Pareto bar with shortcuts

3. "detail/{offerJson}" → FlightDetailScreen
   - JSON string parameter (URL encoded)
   - Detailed flight information

BACKEND API ENDPOINTS
=====================
Base URL: http://10.0.2.2:8000/
  (10.0.2.2 = localhost alias in Android emulator)

1. POST /search/intent
   - Input: {"query": "string"}
   - Output: IntentResponse (parsed request + interpretation + confidence)

2. POST /search/flights
   - Input: SearchRequest (origin, destination, dates, passengers, etc.)
   - Output: SearchResponse (list of FlightOffer with intelligence)

BUILD INSTRUCTIONS
==================
1. Open /android in Android Studio
2. Sync Gradle (File → Sync Now)
3. Configure Android emulator (SDK 26+)
4. Start FastAPI backend on localhost:8000
5. Run app (Shift+F10) or click Run button
6. Test with natural language queries in SearchScreen
